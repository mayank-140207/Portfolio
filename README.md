# Mayank Sharma — Portfolio

A single-page portfolio site built as a "strategy brief" — the visual language of an executive
profile document (ID card, briefing sections, metrics strip, dossier-style timeline) applied to a
personal site. No framework or build step: plain HTML, CSS, and JS, so it runs anywhere and is easy
to edit by hand.

## Files

```
index.html   → all content and structure
style.css    → design system (colors, type, layout) — see :root tokens at the top
script.js    → mobile nav, scroll-spy, reveal animations, animated metric counters, back-to-top
assets/-
  profile.jpg                 
  Mayank-Sharma-Resume.pdf    
```
